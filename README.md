# Donkey Kong Country 3: Dixie Kong's Double Trouble! — Native PC Port (Windows x64)

Complete static recompilation to native 64-bit PC code of **Donkey Kong Country 3: Dixie Kong's Double Trouble!** (Super Nintendo).

## Main Features:
* **Single Executable with Integrated Modern Launcher** (`Dkc3SNESRecomp.exe`): Graphics settings, High-DPI resolutions, controllers, and CRT/LCD/Smooth shaders.
* **Native 16:9 and 16:10 Widescreen Support:** Tailored for widescreen displays and **Steam Deck (1280x800)** fullscreen with zero stretching or distortion.
* **One-Click Presets:** Modern (1080p/144Hz), Steam Deck (800p/60Hz), Original 1994 (Pixel Perfect 4:3).
* **Calibrated 48,000 Hz SNES Audio:** Crystal clear, low latency audio output.
* **Plug & Play Gamepad Support:** Xbox, PlayStation, Switch Pro, and standard USB gamepads automatically detected with tailored DKC 3 button mapping.
* **Save States & Instant Rewind:** Quick saves (F1-F10) and instant rewind (F12).
